# The OpenTelemetry API and SDK (ATS074)

OpenTelemetry Certified Associate (OTCA): The OpenTelemetry API and SDK, worth 46% of the official curriculum. This course belongs to ATP015.

Each section has an introduction, modules with teaching parts, a playground and a graded lab per module, a capstone lab and a quiz. A final quiz closes the course. Labs run on kind (Kubernetes 1.35) with a Python OpenTelemetry SDK service and an OpenTelemetry Collector. Labs and playgrounds are built but UNTESTED: only static checks were run. Technical content remains draft.
