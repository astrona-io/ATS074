# Composability and Extension

This section covers composability and Extension. It develops aPI Independence, SDK Components And Extension Contracts through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain why reusable instrumentation depends on APIs rather than exporters.
- Distinguish SDK providers, processors and exporters.
- Reason about component compatibility and custom extension responsibility.
