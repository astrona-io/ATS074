# Summary

An instrumentation agent attaches supported recording behavior to an application runtime. A Collector agent receives or gathers telemetry near workloads and forwards it through configured pipelines. These roles can cooperate but do not replace one another. Their coverage, privileges and resource use need review. Local placement reduces some delivery dependencies while introducing operational ownership and potential access to sensitive host or application data.
