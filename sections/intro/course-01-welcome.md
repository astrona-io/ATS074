# Welcome To The Course

This course is for learners preparing for the OpenTelemetry Certified Associate (OTCA) examination. It covers The OpenTelemetry API and SDK, worth 46% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations in this course build the reasoning needed to choose an answer, and the hands-on labs let you see each mechanism work in a running application.

At the end, you can explain and compare the concepts in Data Model, Composability and Extension, Configuration, Signals (Tracing, Metric, Log), SDK Pipelines, Context Propagation and Agents. You can also configure the OpenTelemetry SDK for Python through environment variables, read what an OpenTelemetry Collector receives, and find out why telemetry is missing or wrong. Technical terms and acronyms are defined when they appear. Examples use a small Python service named `shuttle`, sometimes a second service named `probe`, and a Collector, all in the `starfleet` namespace. The names identify workloads only and do not change the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching parts, and ends with a summary. Every module has a playground, which is a clean Kubernetes cluster you can explore without any task, and a graded lab, which gives you a task and checks the result on the live cluster. Each section ends with a capstone lab and a knowledge check. A final knowledge check closes the course.

Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. The practice questions are original and are not copied from the examination.
