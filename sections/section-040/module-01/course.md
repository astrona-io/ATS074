# Tracing Requests Through Spans And Context

This module develops tracing Requests Through Spans And Context. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Explain trace and span identity and timing.
- Distinguish parent-child structure from a complete causal explanation.
- Describe context propagation across service boundaries.
- Account for sampling, missing spans and sensitive attributes.
- Choose metric types according to the measured quantity.
- Distinguish cumulative counters from current-state gauges.
- Explain histograms and summaries as distribution evidence.
- Relate aggregation, collection and cardinality to interpretation.
- Distinguish numerical series from individual event records.
- Design structured records with useful identity and timing.
- Correlate logs with metrics without confusing correlation with cause.
- Account for retention, sampling and sensitive data.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
