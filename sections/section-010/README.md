# Data Model

This section covers data Model. It develops resources, Instrumentation Scope And Signal Envelopes through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Distinguish resource, instrumentation scope and observation attributes.
- Explain span, metric point and log record identity.
- Reason about units, timestamps and aggregation metadata.
