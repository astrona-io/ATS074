# SDK Pipelines

This section covers sDK Pipelines. It develops signal Providers, Processing, Readers And Shutdown through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Trace an observation through the appropriate SDK pipeline.
- Distinguish trace sampling from metric aggregation.
- Explain buffering and lifecycle limits without claiming guaranteed delivery.
